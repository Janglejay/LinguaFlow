# Changelog

## Unreleased

## 0.2.1 - 2026-09-05

- Fixed the macOS installer so both input methods are always installed together in `/Library/Input Methods` instead of being silently relocated to stale user-domain paths.
- Added a packaging guard that rejects any future installer containing relocatable input-method bundles.
- Bundled the OpenCC configurations and dictionaries used by the Simplified Chinese schema so the input method no longer falls back to a build-machine Homebrew path.
- Expanded the real Rime smoke check to require bundled OpenCC data and verify `ceshi` produces the Simplified Chinese candidate `测试`.
- After the fixed payload is installed, migrate exact legacy user-domain copies as the logged-in user and store recoverable backups with a disabled suffix so LaunchServices cannot keep launching a stale input-method endpoint.
- Generate installer checksums only after all validation and optional notarization/stapling steps have completed.

## 0.2.0 - 2026-09-05

- Added a self-contained Apple Silicon macOS installer that installs and enables both input sources without requiring Homebrew on the destination Mac.
- Embedded librime and its runtime dependencies in both input-method bundles, with rewritten load paths and bundled license notices.
- Added optional Developer ID signing and Apple notarization support to the installer build pipeline.
- Added English completion candidates with keyboard navigation and concise Chinese meanings generated by Apple's on-device translation model.
- Added a separate `LinguaFlow English` macOS input source with live English-to-Chinese translation and local spelling suggestions that can be accepted with Tab.
- Kept English keystrokes on the host application's normal typing path; translation and spelling remain non-blocking sidecar features.
- Fixed shifted punctuation mapping so Chinese `？` and symbols such as `~` and `|` reach Rime as the keys the user actually typed.
- Prefer InputMethodKit's candidate-placement line rectangle so the panel follows the caret in web and custom text editors.
- Replaced the oversized blue input-source artwork with a padded monochrome template icon.
- Reworked the typing UI into one compact panel with visible pinyin, horizontal candidates, and live English before commit.
- Fixed candidate panel ownership and caret anchoring so stale panels do not remain at screen corners or flash across input sessions.
- Fixed the setup helper's Done button so it closes the window and exits the helper.
- Created the native macOS InputMethodKit application bundle.
- Added Simplified Chinese full-pinyin input through `librime`.
- Added a no-activation candidate and English preview panel.
- Added a 400ms revision-guarded sentence translation pipeline.
- Added on-device Chinese-to-English translation with Apple Translation.
- Added a companion setup app for downloading Apple translation models.
- Added local build, ad-hoc signing, registration, and installation scripts.
- Added core and real Rime smoke checks.
