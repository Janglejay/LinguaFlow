# LinguaFlow 0.2.2 build 8

这是面向 Apple 芯片 Mac 的双语输入法预览版更新，重点修复“宿主文本已经删除，但浮层仍继续翻译旧内容”的上下文不同步问题，并加强两套输入源的升级注册。

## 本次更新

### 删除内容与翻译上下文保持一致

- 当光标位于 LinguaFlow 已追踪文本的末尾且没有选区时，普通 Backspace 会同时从宿主文本和内部翻译上下文移除最后一个完整字符，清除旧译文并触发新的翻译请求。
- 当出现非空选区、光标离开已追踪文尾、Forward Delete，或 Command、Option、Control 等宿主编辑快捷键时，LinguaFlow 不再猜测宿主究竟删除了哪些字符，而是取消当前翻译并清空无法验证的上下文。
- 清空上下文时会推进请求修订号并取消旧任务；即使旧翻译稍后返回，也不能重新显示或通过快捷键插入。
- 中文拼音仍在 Rime 组合区中时，普通退格继续只修改拼音组合，不会误删已经提交的中文上下文。

这个策略只追踪当前输入会话中由 LinguaFlow 自己提交的文本，不读取宿主文档的任意历史内容，也不保存原句或译文。

通过鼠标或上下文菜单直接修改宿主文本时，InputMethodKit 不一定立即产生按键事件；LinguaFlow 会在下一次可观察的输入事件中对账，并在发现光标或选区与已记录位置不一致时丢弃旧上下文。

### 两套输入法均保留

同一个安装包仍然同时包含：

- `LinguaFlow 中文`：Rime 全拼候选、中文输入和实时英文预览。
- `LinguaFlow English`：英文直输、单词补全/拼写纠错候选、候选中文释义和实时中文预览。

如果安装后“系统设置 → 键盘 → 文字输入 → 编辑”暂时只显示其中一个，请先关闭并重新打开系统设置。安装器会对两套输入源分别注册、启用并重试验证；通常无需重启整台 Mac，如果当前登录会话仍未刷新，请先注销并重新登录。

## 安装与升级

1. 从 `v0.2.2` GitHub Release 下载 `LinguaFlow-0.2.2-macOS-arm64-unsigned.pkg`。
2. 双击安装包并按提示完成升级；中文和 English 会一起安装到 `/Library/Input Methods`。
3. 安装后先切换到任意系统输入法，再分别切回两套 LinguaFlow 输入法测试。
4. 第一次使用翻译时，从输入法菜单选择“准备本地中英翻译…”，允许 Apple 下载设备端中英翻译模型。

从 0.2.0 或用户目录开发版升级时，安装器只迁移 Bundle ID 精确匹配的旧 LinguaFlow 副本，并将其保存到用户的 LinguaFlow 备份目录；不会删除其他输入法或个人 Rime 数据。

## 验证

本版本通过了以下检查：

- 翻译上下文、连续退格、句末标点和光标/选区对账的核心状态检查。
- 真实 librime 拼音检查：`nihao → 你好`、`ceshi → 测试`。
- Apple 设备端中英互译检查。
- 中文、English 与设置助手的 release 构建、应用签名结构及安装包结构检查。
- 安装后两套输入源的启用、可选择状态和系统路径解析检查。

## 系统与签名说明

- 支持 Apple 芯片 Mac。
- 要求 macOS 26 或更新版本。
- 当前预览安装包尚未使用 Apple Developer ID 签名或公证。如果 Gatekeeper 拦截，请在“系统设置 → 隐私与安全性”中确认“仍要打开”。
